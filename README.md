# To-Do List App

![To-Do List App Preview](./todo-project-optimized.jpg)

A responsive task management application built with HTML, CSS, and JavaScript.

Live Demo

"View Live Demo" (https://mohsennikpey.github.io/mani-projects/todo-app/)

Features

- Add, edit, and delete tasks
- Mark tasks as completed
- Manage task priorities (High, Medium, Low)
- Filter tasks by All, Active, and Completed
- Clear completed tasks
- Save tasks using LocalStorage
- Responsive design for mobile and desktop
- Safe handling of user input

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

Installation

1. Clone this repository:
   "git clone https://github.com/mohsennikpey/mani-projects.git"
2. Open the "todo-app" folder.
3. Open "index.html" in your browser.
